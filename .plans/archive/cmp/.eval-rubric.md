# Review rubric for one language sample in cmp/<lang>/

You are an independent reviewer. You did not write this sample. Read cmp/SPEC.md first (the shared
spec, note the 2026-09-29 revision of Model 2), then every file in the sample directory. For
reference on the intended semantics, skim temporal/model/Temporal/Feature/Nexus/Caller/Model.lean.
Do not run any toolchain. You may use `gh api repos/<owner>/<repo> --jq '{pushed_at,archived}'` to
spot-check library claims.

Report in this exact structure, concise, with file:line citations:

## Scores (1-5, 5 best) with one sentence of justification each
1. Spec fidelity: both Models complete, names exactly as SPEC.md, section order, revised Model 2
   applied (pauseRequested -> started; visible retry rows), pins present.
2. Language plausibility: would a fluent expert accept this as idiomatic? Any invented syntax,
   misuse of a language feature, or code that could not work even in principle?
3. Authoring readability: how the Model files read for someone who mostly reads and rarely writes.
   Ceremony versus content. Does the declarative part look like configuration or like code?
4. Check story accuracy: does the README's claim of what is checked at compile time versus test
   time match what the language can actually do? Flag overclaims.
5. Framework realism: is the umpire surface believable and sufficient for the Models to bind to,
   or hand-waved where it matters (finite enumeration, refinement check, search)?
6. README honesty and library table: are costs stated plainly? Spot-check two library
   maintenance claims with gh api and report whether they match.

## Red flags
Bullet list. Anything that would mislead a decision maker: invented APIs, semantic drift from the
spec (e.g. a step enabled in the wrong phase), a claimed compile-time check that is really runtime,
a library described as maintained that is not.

## Strengths
Bullet list, three to five items, specific.

## One-paragraph verdict
What this sample demonstrates about the language for the Umpire model layer, and the single
biggest reservation.
