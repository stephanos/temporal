# fn-37-hard-cut-umpire-vocabulary-and-current.3 Rewire model languages to fingerprints, Limits, and Known Gaps

## Description
Complete R2 and R3 across the checked authoring and planning languages. This task replaces arbitrary digest strings and bound/omission vocabulary while leaving the v2 wire encoding to Task `.5`.

**Size:** M
**Files:** `model/Umpire/{Target,Property,Behavior,Query,Planning}/**`, `model/Umpire/Core.lean`, current Artifact adapters, Temporal model/config consumers
**Touches:** [model/Umpire/Core.lean, model/Umpire/Target/**, model/Umpire/Property/**, model/Umpire/Behavior/**, model/Umpire/Query/**, model/Umpire/Planning/**, model/Umpire/Artifact.lean, model/Temporal/**/*.lean]

### Approach
- Replace every behavior-bearing `semanticDigest`, `contractDigest`, and matching helper with typed `behaviorFingerprint` derivation in the owning checked language.
- Define the smallest canonical behavior view in each owner module; exclude source locations and documentation, and remove arbitrary author-supplied fingerprint labels.
- Rename `BoundUnit` and `TypedBound` to `LimitUnit` and `Limit`; rename bound exhaustion/status/diagnostic fields to Limit Reached vocabulary without changing completeness claims.
- Rename planning omissions to typed or closed Known Gaps and propagate them through selected plans.
- Replace context-specific `semanticIdentity` uses: Definition ID ordering becomes `definitionId`; artifact identity remains for Task `.5`.
- Preserve separate Target, Property, Behavior, Query, and Planning ownership rather than centralizing canonical views in Core.
- Add mutation tests proving behavior changes move fingerprints and source/documentation changes do not.

### Investigation targets
**Required** (read before coding):
- `model/Umpire/Target/Language.lean` — checked Target fingerprint and Capability Contract ownership.
- `model/Umpire/Property/Language.lean` — Property canonical behavior view.
- `model/Umpire/Behavior/Language.lean` — Behavior canonical view and occurrences.

- `model/Umpire/Artifact.lean:30-110` — temporary source adapter that must keep compiling before v2.

### Key context
A Behavior Fingerprint is generated, not an author-facing version label. Limit Reached must remain distinct from Exhaustive Search; renaming must not strengthen any result.
