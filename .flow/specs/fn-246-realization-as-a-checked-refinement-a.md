## Architecture & Data Models

**Runtime capabilities.** Identity, Snapshot, Evidence<K>, Fill<A> and ReplyPolicy assemble Realize. Required capabilities are Rust trait bounds; optional behavior has explicit defaults. Fill has one associated typed request and receives the action plus declared World, inputs and admitted identity. All four consumers use that definition. Existing wire envelopes remain the transport authority; the typed seam can later consume fn-237.4's feature-owned worker-evidence wrapper without moving that wrapper/journal/gate implementation or claiming its live proof here.

**Action registry.** Each Model action variant carries one Temporal declaration. RPC declarations bind the descriptor method, filler and evidence predicate; environmental declarations state the abstract event. Generic DSL metadata forwarding carries inert variant metadata without knowing RPCs. Temporal annotation admission checks descriptor identity, action coverage, actual generated result types and claim coverage. Client proposals, worker rows, probe baselines and catalog examples read the same registry.

**Shared Temporal layer.** A descriptor-generated WorkflowService catalog owns API identity and shared field kinds/limits. Each feature explicitly claims what it reads and fills. Unclaimed fields are Ignored; explicit required/semantic constraints remain authoritative. One entity lens owns bootstrap/admission, identity, receipt, proposal correlation, immutable evidence, read finality, hold instructions, freeze, Reset and program-envelope assembly. It delegates feature semantics through typed projections and policies. Shared API/domain names are valid; imports of feature modules and embedded feature policy are forbidden.

**Reach.** Reach carries an associated typed observable target implementing a pure compatibility check against candidate full Model states. Exact<State> preserves complete-state matching for Kettle and complete observations. The activity target contains only validated actual fields and explicit unobserved fields; a snapshot cannot fabricate Remaining budgets from defaults, configured timeouts, elapsed time or desired outcomes. Full candidates come only from existing checked_step/replay. Partial observations additionally require the bounded compatible-frontier contract below; a typed predicate alone cannot make greedy hidden-state commitment sound.

Reach uses admitted finite depth/work/retention and complete typed evidence. Predicates inspect source, action, choice, outcome, candidate state and evidence cursor/consumption position alongside the complete observation prefix. Target compatibility cannot authorize intermediate edges or replace action/cause/history evidence. Search order is path length, action-catalog order and transition-choice order. Current and ordered Candidates remain available. Canonical first-valid order selects a report witness; it cannot discard future-relevant compatible hidden branches. Exact/singleton behavior stays pinned.

A successful replayable match produces the normal prepared judgment after every canonically preceding candidate has been resolved. Longer cyclic or other unexamined alternatives do not force that success to refuse and do not justify global uniqueness or exhaustive-search claims. Complete admitted-scope no-match prepares Unexplained; a no-match is truncated when an otherwise evidence-compatible frontier remains unexamined at the depth/work bound, even if all shorter paths were visited. Truncated no-match, or work exhaustion before canonical precedence can be established, produces a named Refused bound. Later frontier exhaustion does not revoke a valid first match. Search prepares a judgment without mutating state, pending proposals or receipts. Publication precedes commit.
