Smallest proposed contract declaration

Add one enum-valued proof_contract field to ordinary ResetResponse, using tag 2 after the existing opaque program. Give the enum exactly one supported nonzero current value, e.g. PROOF_CONTRACT_WHOLE_PREFIX_V1=1, and zero UNSPECIFIED. The exact spelling remains an implementation choice. Proto3 cannot express required presence directly, so Host admission must reject absent/default zero and every other numeric value. A scalar enum is sufficient because absence and explicit zero are both invalid. A bool or caller option cannot distinguish a malformed/default response from an admitted current contract.

The declaration means every successful Explanation is the whole witness from the accepted Reset against the actual observation and callback/proposal prefix. Earlier reports remain immutable existential claims for their own prefixes, and consumers cannot concatenate explanations as deltas. The value advertises the real bounded singleton implementation; it supplies no claim that the compatible frontier already exists. Program remains optional and opaque, so an unconfigured/unsupported-program Reset still declares the contract.

Use one framework-owned current ResetResponse constructor/helper adjacent to the generated protocol/runtime surface. Generic Runtime and composing dispatchers should call that helper when they actually reset or configure the same current runtime. Do not introduce a Realize override that lets adapters choose an older/different proof mode. The helper avoids three independent literal declarations, while explicit runtime controls establish that the assertion is true.
