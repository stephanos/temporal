Linux process ownership uses a private session and PR_SET_CHILD_SUBREAPER. Timeout, cancellation, owner-death and signal controls verify recorded descendant PIDs disappear after reaping, including a separate-session child. Every supervised Darwin invocation applies child-only hard/soft RLIMIT_NPROC=0, with real/effective root refused. This prevents descendants rather than supplying Darwin subreaping. Retained log file handles, metadata polling and bounded reads avoid producer-EOF waits and tool-controlled log reopening.

The Linux uid1000 simulated-Darwin control applies the real NPROC0 limit and proves a helper cannot create a separate-session descendant. The TLC installer containment preflight reaches its unchanged diagnostic under that limit using Bash builtins. Actual shasum succeeds under Linux NPROC0; mise aborts while creating Tokio threads, so that probe is inconclusive for Darwin, whose NPROC behavior differs.
