Linux process ownership uses a private session and PR_SET_CHILD_SUBREAPER; timeout, cancellation and owner-death controls verify recorded descendant PIDs disappear after reaping, including a separate-session child. Darwin JVM launches use an explicit internal Java policy marker and child-only hard/soft RLIMIT_NPROC=0, with real/effective root refused. This prevents JVM descendants rather than supplying Darwin subreaping. Darwin policy wiring is unit-tested on Linux; actual macOS Temurin 27 execution remains unverified. General helper commands retain their existing process-group execution on Darwin.
