Use it only at legacy TCP hooks and their mapped-handle fallthroughs. Resolver/interface hooks and generated UDP/IP/Unix/packet/DNS refusals retain `NetworkEnabled`. The runtime owns an early scalar boundary-activation predicate parsed from the checked selected bootstrap. The syscall/leaf edge reads it through a nosplit scalar accessor before gomadio.init registers the backend, without a syscall-to-gomadio import cycle. Otherwise a pre-registration syscall could see the boundary as disabled and fall through to the host. Selected activation with no backend must refuse; gomadio's later enabled flag cannot determine early syscall ownership. Defer the accessor's exact path to .1's frozen interface.

The selected runtime can check generic-dispatch support before package initialization, but backend registration occurs later in gomadio initialization. Preparation must prove that a registration anchor is linked and precedes every potentially socket-capable package initializer, including variable initializers and functions/indirect calls they can invoke. A dependency path through net to gomadio establishes order only for paths that depend on that anchor. Independent package initialization that can call a socket before it remains inadmissible. The admission receipt records the proved ordering and exact source inputs; unresolved initializer flow fails preparation before launching the target. Early activation and edge refusal complement this startup proof; they do not replace it.

Raw-syscall-only targets without a proven anchor remain unsupported. A blank net import in one fixture proves only that fixture's order. This design adds no syscall-to-gomadio import, implicit source rewrite or host fallback. Actual .1 registration interfaces and an executable init-order proof are prerequisites for .2 startup acceptance. If the existing anchor cannot prove that requirement, root must admit an explicit init/link design before claiming support; source preparation and an eventual missing-backend error cannot substitute for the startup requirement.
