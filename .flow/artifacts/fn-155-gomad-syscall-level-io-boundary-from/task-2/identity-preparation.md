## Bootstrap and initialization

The current 212-byte bootstrap contains five hashes and a seed, with kind 1 and a checksum. It contains no profile name or option payload. Host `DecodeBootstrapFrame` hard-codes Default; runtime `gomadReadConfig` reads exactly 212 bytes and validates only the header; `gomadio.init` checks the wire checksum, not the hashes against a known profile. The runtime generated comment about later identity validation should not be mistaken for that validation actually existing. [bootstrap.go](../../../../tools/gomad3/deterministicio/bootstrap.go), [iowire.go.tmpl, lines 36–80](../../../../tools/gomad3/deterministicio/schema/iowire.go.tmpl), [runtime/gomad.go, line 1785](../../../../tools/gomad3/toolchain/runtime/overlay/src/runtime/gomad.go), [gomadio.go, line 28](../../../../tools/gomad3/toolchain/runtime/overlay/src/internal/gomadio/gomadio.go)

Recommend an additive, bounded selected-profile bootstrap form, retaining the old frame and golden bytes for the empty selection. Its decoded payload must carry a canonical boundary selector and exclusion identity, bind them to the inventory/implementation hashes, reject unknown variants, and expose the selected boundary to .1's leaf edge before socket operations. Update early runtime length/header handling and the generated host/overlay codec together. Do not attempt to recover arbitrary exclusion sets from a hash, encode a switch only in a raw environment variable, or enumerate every adapter subset as a profile table. The process transport already carries opaque IOConfig bytes with a 4096-byte bound. [process.go, line 20](../../../../tools/gomad3/runner/internal/execution/process.go), [bootstrap_unix.go, lines 50 and 81](../../../../tools/gomad3/runner/internal/execution/bootstrap_unix.go)

There is no universal backend-init anchor in this base. `net` and `crypto/rand` import `gomadio`; `os` imports only its `mount` subpackage. `gomadio/network.go` imports os and internal/poll, so making syscall import gomadio creates a cycle. A raw-syscall-only program can therefore omit the backend entirely. Require preparation to reject a selected target without a proven registration anchor, and require the edge to refuse missing registration. A fixture's blank net import proves only that fixture. General raw-only support needs an explicit linker/init-order design and task amendment before being claimed; it cannot be established by this report or by checking only that gomadio appears somewhere in the closure. Unsupported generic dispatch must independently fail before user initialization, with the injected-table case required by .2.
