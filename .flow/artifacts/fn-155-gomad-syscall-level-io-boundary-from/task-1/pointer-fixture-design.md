## Selected mechanism

Use a host-only runner under `toolchain/runtime/testdata/vfdpointer/`, called after the existing `Makefile` overlay-test package list. It reads the selected toolchain's `src/syscall/gomad_vfd_unix.go`, verifies equality with the frozen repository source, and creates a private temporary `-overlay` manifest. The manifest replaces that file with four exact growth-call insertions and adds synthetic shim/test files to package syscall. Capture baseline, instrumented source, manifest, tool identities and command results. Removing precisely those insertions must reproduce the original bytes. Changed signatures, unmatched anchors or unexpected source differences fail the runner.

The shim uses operation-specific noinline recursion with a live 1 KiB frame for 64 levels, following `gomadGrowStack`. It runs on the caller G with a P. It returns or records numeric addresses only. It never retains a caller pointer, invokes a callback, allocates a caller-pointer container, or changes arguments or bytes. Original typed helper parameters remain live for the unchanged production body after recursion. Compiler diagnostics must show that the shim frames survive optimization and all tested objects stay on that G's stack.

| Actual helper | Injection point and roots | Required observation |
| --- | --- | --- |
| `gomadGenericWritev` | First statement, before slice construction, Len/Base reads or allocation. Pass only `p *Iovec` into recursion. | The array and both stack Base targets move before the owned copy. |
| `gomadVirtualAccept` | First statement, before flags/nil checks or backend entry. Pass `raw` and `length` together. | Both output objects move before address copy and length write. |
| `gomadVirtualName` | First statement, before nil checks or Local/Remote. Pass both output pointers together. | Both objects move for sockname and peername. |
| `gomadVirtualGetsockopt` | First statement, before its `*length` read. Pass `p` and `length` together. | Both value and length objects move, including SO_TYPE which has no backend query. |

For writev, record the old array and Base addresses in the caller as scalar witnesses. At shim entry, record the array address without dereferencing it and require equality with the caller's recorded array address. This establishes that the old Base observations describe that entry stack. Recurse with only the typed array root. At the deepest frame, observe the relocated array and its two Base fields, then return to the unchanged copying body. No additional typed Base temporary may cross recursion and conceal the caller-array pointer-map requirement. Earlier incidental relocation makes that fixture inconclusive and fails its proof assertion.

A separately generated large-frame copy of the helper establishes only that copy's behavior and is rejected as production proof. A large-frame insertion into the actual helper could be valid, but requires proving the added array neither escapes nor disappears. The selected typed recursion uses the existing bounded growth pattern and preserves every original statement. Its result is an instrumented stress-path witness, supplemented by original-source maps and ordinary uninstrumented native tests. It cannot alone certify every instruction in the shipped binary.

## Fixture cases

Each success case runs on a fresh goroutine in a disposable syscall-test child, with fixed caller arrays and adjacent sentinels. Compare scalar addresses solely as observations. Require actual address changes, exact bytes, both outputs, intact surrounding storage and the expected errno/count. An unchanged address is inconclusive and fails; it must never become a pass or skip on a claimed native gate.

- Writev uses two stack payloads and a stack `[2]Iovec`. Require all three addresses to move, both relocated Bases to point at the caller's current arrays, and a six-byte partial result crossing the vector boundary with bytes `abcdef`. Repeat a full result. Retain the existing 64 KiB owned-copy bound, nil Base and overflow cases; the large heap case remains bounds evidence only.
- Accept returns a distinctive fixed IPv4/port and a fresh virtual descriptor from the stub backend. Check both pointer witnesses, decoded sockaddr, full reported length, and accepted-descriptor cleanup. Include the null/null valid form and mismatched null outputs as ordinary error cases without claiming their absent-object relocation.
- Sockname and peername return distinct fixed backend addresses. Exercise full-size output and a short supplied length, verifying bounded prefix copying, untouched remainder, full length reporting and both moving objects. Length lives inside its own guarded stack struct.
- Getsockopt SO_TYPE writes SOCK_STREAM and length 4 into separately guarded stack storage. Repeat SO_ERROR with a backend status yielding a distinctive errno value. Include a short length that returns EINVAL and preserves bytes/length. Growth precedes even that length validation.
- Keep read/write movement for all existing generic variants. Extend Linux pointer-pair calls through actual Syscall6/RawSyscall6 where their arity requires it. Darwin test exports call the existing libc trampolines through syscall/syscall6/raw equivalents and X variants where present; helper-only exports are supplemental coverage. Exact pinned x/sys execution retains its separate gate.
- Retain ordinary refusal cases for nil positive-length buffers, vector count above 1024, unsupported options/accept flags, stale virtual descriptors, UDP, reserved descriptors and non-descriptor first arguments. Assert their existing errno/refusal behavior and untouched output storage where applicable. Invalid pointers outside the supported unsafe contract are not relocation fixtures.

The fixture compares pre-growth and deepest-frame addresses for each output pointer. It never dereferences a saved uintptr. After return, it checks the caller's typed objects and sentinels. Compiler diagnostics must explicitly establish stack residence for the output structs, payloads and iovec array; a moved G with any heap-only tested object does not satisfy that case. A no-growth control must fail the relocation predicate, showing that unchanged memory cannot silently pass.
