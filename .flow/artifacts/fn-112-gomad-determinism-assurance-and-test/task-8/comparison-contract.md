Every raw Campaign and each retained Artifact is opened through the built CLI `inspect --json`. Inspection validates journal hashes/segments, canonical execution manifests, file inventories/hashes, referenced stored byte counts, outcome/selection matching and summary totals. The test separately decodes every raw manifest with record.DecodeExecutionRecord before semantic comparison.

The comparison copies the entire decoded CampaignInspection and ExecutionInspection, rather than selecting fields. It normalizes campaign IDs and retained Artifact references and omits the journal reference (segment/hash/byte counts). It excludes elapsed host time, physical retained-success byte counts, and individual success Artifact byte counts. Full decoded manifests normalize CampaignID, CreatedAt, Host, Limits.OverallTimeoutNanos and RecordHash only. All remaining fields, including execution and retention counts, outcomes, output hashes/lengths, transcripts, World snapshots/transitions/terminal identities, target/Runner/toolchain/environment and other bounds, compare exactly. This fixture uses the valid None World, whose snapshot/transition hashes are compared; it exercises a nonempty deterministic filesystem transcript.

The coordinator calculates its child timeout from time.Until(deadline) in runner/coordinator.go, so the recorded remaining overall host budget varies. record.FinalizeExecutionRecord hashes the full record projection, including Limits, making RecordHash depend on that budget. Artifact storage includes the serialized manifest with CreatedAt/Host RFC3339Nano timestamps and decimal remaining-budget fields, whose lengths vary. Therefore physical storage totals need not match semantic executions. runner/internal/campaign/retained_evidence.go validates actual StoredBytes against each journal SuccessArtifactBytes, and open_campaign.go validates RetainedSuccessBytes against their sum; every CLI inspect call retains those independent checks.
