## What changed

- One table, `rewrittenModuleAdapters` (`adapter_rewrite_test.go`), now drives the adapter
  template for sprig, validator, sentry, pebble, cactusstatsd, memberlist and
  hashicorp-metrics: `TestRewrittenModuleConsumers`, `TestRewrittenModulesRejectChangedIdentity`
  (all three original changed identities, now with the `identity mismatch` text for every
  adapter), `TestRewrittenModuleRewritesPreserveCommentsAndRejectDrift` (every rewritten file,
  comments plus the four drift cases), `TestRewrittenModulesRejectUnrewrittenInventoryDrift`,
  and an unrewritten-file byte-equality check in `TestRewrittenModuleInventoriesMatchPinnedModules`
  (Pebble's MemFS check, now for all seven). Sentry's subprocess-import checks and Pebble's
  `nm` check are row hooks. Five test files deleted; memberlist keeps only the env-gated
  `TestMemberlistSuppliedTCPConsumer`, hashicorp-metrics only its default-registry consumer.
- `TestProfileRejectsAdapterConfigurationDrift` replaces the sentry and hashicorp-metrics
  tables and five gRPC tests (7 cases x 3 adapters; each adapter gains the cases it lacked).
- `TestManifestInterceptsBeforeHostDispatch` replaces the filesystem and network patch tests;
  `TestPinnedAdapterModuleInventories` replaces three pinned-inventory tests.
- `architecture_test.go` keeps the import and export rules (`TestPackageArchitecture`,
  `TestExactModuleEdges`, `TestPublicPackagesDoNotExportTypeAliases`,
  `TestDomainModulesDoNotExportWireFraming`) and the Makefile gate-ownership check; 11
  deleted-file, banned-word and required-filename tests are removed, each with a reason in
  `mapping.tsv` / `mapping-check.py`.
- `TestAdapterSourceEditsReplaceEveryAnchor` now asserts that regeneration moves a version
  literal in a test file (that branch was covered only by literals the merged tables no longer
  spell out).

Two deliberate differences: the consumer template compares each listed platform's source set
with that platform's pin (`...ByHost[platform]`), not the host's pin for both listings. On the
qualified hosts the values are equal for these five adapters (both map entries are identical;
Pebble already did this). On linux/arm64 the host pin is empty, so the old sprig, validator,
sentry, memberlist and cactusstatsd consumer tests failed at that comparison after running
their fixtures (baseline failures); the template rows pass here, exercising every assertion.
The hashicorp-metrics comment check is skipped: its rewrite removes code with its comments,
and no old test asserted comment preservation for it.
