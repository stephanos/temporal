# Terminal module receiving boundary

This is a pure reader and private-observation capture boundary for the dedicated terminal module producer. It does not launch a compiler, build, guest or inspection command. The existing campaign, runtime and one-box observation selectors retain their validation paths.

API: `terminal_module_receiving.read_module(config, stage_root, descriptor_path) -> descriptor`. The only endpoint is `config.root/stages/terminal-module/primary/module/terminal-module.json`, with the stage's actual `primary-final.command.json`, `.process.json` and `.stdout`. The producer is the current frozen ordinary measurement executable authenticated by `primary_stages.native_bootstrap`, not an arbitrary frozen file. Its exact argv is `[producer,--prepare-terminal-module,config.terminal_module_spec,output_root]`. The closed frozen SPEC contains schema, repo, stock_go, toolchain_cache and optional explicit absolute temporary_directory.

The closed 15-field `gomad.native-terminal-module/v1` descriptor binds five payload path/hash pairs, the original compilation recipe, original wire configuration, memory and fuel. Recipe validation requires original ./tests go-test, exact ordered three tags, and empty target arguments. Original integration configuration remains nil Args, PWD=/workspace, zero entropy, cooperative clock step0, output1MiB/transcript8MiB/calls10000/descriptors64/files1000/filesystem8MiB/pending4096, memory4GiB/fuel2^50. The later full Temporal execution configuration is separate.

Native preparation requires explicit bookkeeping beyond the old Go Spec: choices enabled with1GiB limit, diagnostics disabled,30min timeout,1MiB output,64MiB retained World capacity, normalized `gomad-target` argv and native profile environment additions. The reader checks this normalized provenance exactly, separately from the original wire tuple. No guest execution or terminal proof is inferred from module preparation.

The private receipt's record commitment is the exact module provenance SHA; no campaign Record/plan is fabricated. The reader independently verifies the raw compilation/admission command projection, full compiler and transitive source closure, exact raw output caps, cache provenance and source/module/compiler commitments. Fresh installation compiler_inputs must equal a matching current **frozen installation** inventory and every member's frozen bytes; wrong-cache/missing witnesses or unlisted generated auxiliaries fail closed. Runtime implementation is recomputed from five frozen generator/runtime fragments. Actual WASM metadata is decoded from the module and the complete cooperative-v1 import set, listed optional imports and signatures are enforced.

Descriptor and raw payload reads use bounded nonblocking descriptor opens, owner/mode/single-link checks, stable pre/open/post/named identities and hashes. Sidecar traversal admits only the exact bounded declared tree. Actual command PID, source/candidate seal, stdout hash, complete process registration, frozen send epoch and admission timestamps are bound before returning a descriptor. Its final snapshot must still equal the authenticated descriptor hash, preventing an unvalidated reread from escaping the seal.

Nine focused Python tests use explicit synthetic retained fixtures, actual files and actual WASM metadata bytes; no compiler or guest executes and only the separately covered bootstrap is mocked. They cover original tuple refusal, unlisted/changed/aliased/private raw inputs, wrong PID/argv, unknown installation fields, wrong normalized runtime policy, frozen inventory omissions/missing cache witnesses, stale attempt/process times and descriptor replacement after capture. Temporarily removing the final descriptor-hash guard causes exactly one targeted regression to fail: `/home/agent/terminal-module-descriptor-red.log`. The restored source passes the complete local driver discovery:280 tests,10.328s, `/home/agent/terminal-module-final-driver-green.log`. Nine of these are preserved unrelated untracked old support draft tests, so the tracked suite count is271; those drafts are not staged.
