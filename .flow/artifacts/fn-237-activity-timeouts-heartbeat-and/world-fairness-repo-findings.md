## Reuse decision

Reuse the typed World environment and existing literal assumption parser. Add one bounded conditional assumption plan and a primitive guard selector; there is no existing general World constant-folding facility to reuse. Do not extend the native policy or build a general evaluator.

* `front/src/body/mod.rs:198` creates the method environment; `:206` binds each actual parameter field to typed `ExprKind::World(field_name)`; `:224` verifies a helper receives the selected World parameter itself. `Env::insert`/`shadow` at `:33`/`:40` already remove stale World identity when a name is shadowed. Keep this identity machinery rather than deciding by a parameter's spelling.
* `front/src/body/expr.rs:86` reads parentheses/groups; `:101` resolves locals and source constants; `:127` reads typed World fields through that environment; `:168`/`:182` handle unary/binary typing. Parse guards with an empty state environment and actual method/helper locals, with expected `Bool`. Admit only the agreed primitive World boolean/comparison grammar. Validate the authored guard node set before any simplifying constructor can erase a prohibited dependency or call. All branch bodies must be admitted, including inactive ones.
* `front/src/body/typer.rs:68` already maps comparison and boolean operators. Primitive `Type::Bool`/`Type::Int` remain the boundary: O added `Bounded`, `Optional`, `Payload`, `Some` and `OptionalOr`, but they are outside this prerequisite's guard grammar.
* `ir/src/expr.rs:89` folds only literal boolean `And`/`Or`; `:106` folds literal `Not`; `:122` folds equal conditional arms. It does not substitute selected World values or evaluate comparisons. Preserve these helpers and add only the admitted primitive guard operation. Typed source constants already arrive as expressions; do not assume every constant is a literal or extend arithmetic evaluation to make more constants work.
* `backends/tla/src/bind.rs:24` and `:188` provide validated World values in declaration order, rejecting missing/duplicate/undeclared/mistyped fields. `:238` converts typed literals, including O's nominal encoding. Consume the validated primitive values, not raw binding entries or optional ordinal encodings.

The narrow resolver should receive validated primitive World values and a typed admitted predicate, select exactly one leaf, preserve the outer named assumption identity/location, and return an ordinary flat assumption. Put shared plan/predicate semantics in IR or another already permitted dependency shared by native and TLA; neither front nor TLA may import the native interpreter. A small Bool/Int comparison selector is sufficient. Do not expose `Resolver`/`Frame` as a generic evaluation service.
