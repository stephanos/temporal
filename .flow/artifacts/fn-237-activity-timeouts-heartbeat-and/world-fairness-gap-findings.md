### Naming validation needs an explicit design choice

`Lift::named` calls `names::assign` and `names::validate` before `bind`. `names.rs:345` reserves `Assumption_<name>` only for registered scopes already matching progress; `:367` reserves `Fair_<claim>_<action>[_<ordinal>]` only from the flat `fair` list. An unresolved plan with empty flat fields can therefore skip collision checks and later emit an unchecked selected operator. Two different plans may also resolve to equal flat scopes and introduce a named alias that did not compare equal before selection.

The recommended bounded fix adds `backends/tla/src/names.rs` as a fifth production owner. Its collision validation reserves generated fairness symbols reachable from conditional leaves and the registered aliases that conditional selection can introduce. This is name reservation only and never unions policy, validates an inactive catalog value or changes emitted fairness. Preserve flat-only collision behavior. Tests should include a state field or authored identifier named like a conditional-only `Fair_<claim>_<action>_<ordinal>`, a unit fair action's exact operator and registered/progress plans that become equal only for one World.

An alternative is selected-plan revalidation after binding. The current TLA `Lifted` does not retain `front::Source`, which `names::validate` needs for occupied identifiers and located diagnostics. That alternative needs an explicit retained-source/lib.rs change or a different narrow reusable validation contract. Do not claim a four-file implementation can rerun the existing validator from `bind.rs` alone.

The baseline four production owners remain correct for the grammar/resolution path. This uncovered validator dependency makes five owners the safer planning estimate. `emit.rs` may be a sixth owner if direct unresolved-plan refusal cannot be guaranteed at existing successful bind boundaries. An M still has one observable capability and four acceptance clusters; do not manufacture a parser/resolver split to hide this control. Fresh review should assess the actual final owner count and representation.
