## Independent source handoff

The smallest handoff is one explicitly owned World plus its explicit complete start set, carried through a typed per-fixture binding route. The plan must fix its field/type representation and the point where fixture generation supplies it. `Lift::source/parse` currently only reads source; `lift::build::generate` eagerly emits artifacts and separately generates a native backend call from `metadata.world_path`. A constructor expression string alone cannot prove that source emission and native replay selected the same values. Preserve source-only unit APIs and artifact bytes while adding that explicit route. Reuse the current source interpreter; do not invent a second evaluator to execute arbitrary computed-start Rust.

The binding needs field/type correspondence, deterministic order and located failures for missing, extra, duplicate or wrongly typed values. World constants, source constants, current-state fields and before-state aliases need distinct lookup identities and collision-safe TLA names. Carry the identical selected values into main, invariant, postcondition, negative and progress CFGs, including empty-start cases. Keep unsupported World field types as located refusals.

Computed starts are alternatives of complete states. A correlated pair must never become the Cartesian product of its individual fields. The parent permits enumerating a declared start set; the source transition relation and claim meaning must still come from authored source independently of native reached states/edges. The plan should say how the selected start set binds to the authored computed-start declaration and how malformed, incomplete or mismatched bindings refuse. Do not use checker output to synthesize Next or claims. Reuse current Type/Expr/Diagnostic and backend replay mechanisms rather than add another serialization or evaluator subsystem.
