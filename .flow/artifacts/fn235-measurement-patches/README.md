# fn-235 measurement instrumentation patches

Uncommitted private-measurement patches from the closed fn-235 worktrees, kept so the
10-virtual-second wall checkpoint and phase-progress instrumentation can be reapplied
(for example by fn-185.2 or fn-232.13's ringpop receiver). File names carry the base
commit each patch applies to. They change no guest, model, evidence or scheduling
behavior and must never land in a release helper. Results: `../fn235-commitment-cost-2026-10-21.md`.
