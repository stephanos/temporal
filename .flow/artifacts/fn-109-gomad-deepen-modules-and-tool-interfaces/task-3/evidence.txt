Design
- runner/internal/campaign/controller.go: FinishAttempt + RecordSuccess/RecordCancelled/
  RecordFailure are replaced by Complete(Completion) bool. Completion is an opaque value built by
  CompletedSuccess, CompletedCancelled, CompletedFailure(domain, reason, distinctFailures) or
  CompletedUnclassified (an attempt that ended before classification; counts as attempted only).
  One call releases the slot, increments Attempted and the classified counter, sets
  DistinctFailures and applies the first/budget stop, returning whether active work must be
  cancelled. Next, Stop, Stopped, Active, Done, Finalize, Statistics, ordinal scheduling and the
  restored-policy check in NewSeedController are untouched. The controller stays pure.
- Invariant violation: completing without active work, or with the zero Completion, panics
  before any mutation (as FinishAttempt did). Chosen over an error return because runLocal has
  no error slot for it that would not add a new HostError reason or reorder its precedence; the
  loop only receives completions of jobs it launched, so the panic is unreachable.
- runner/runner.go seed loop: the per-completion body runs in a closure (continue -> return;
  `git diff -w` shows the logic change: 41+/28-). A local `complete` helper applies
  Complete once and synchronizes the summary; classified completions call it where the old
  Record* call sat (cancelled before partial preservation, success only when hostFailure is nil,
  failure before the artifact path/journal append so first-failure StopReason and cancel are
  unchanged). Any completion the body did not count is counted as unclassified after the
  closure, so no early return loses an attempt. The two early returns that publish a Runner
  failure (supervision error, World record) count first: publishRunnerFailure writes
  summary.DistinctFailures directly, and counting afterwards would overwrite it with the
  controller's value (pinned by the "supervision failure" and "malformed World" rows; a
  mutation removing the early count fails TestSeedCompletionKeepsCampaignStatistics).
- Timing note: an unclassified attempt is now counted at the end of its completion's handling
  instead of on receipt. Nothing between reads Attempted/Active or the synced summary counters
  (single goroutine; Done() is evaluated only at loop top), so observable statistics are equal.
  Crash/resume windows are unaffected: the controller is in-memory and resume restores
  statistics from the journal (restoreResumeSummary), whose writes are unchanged.
