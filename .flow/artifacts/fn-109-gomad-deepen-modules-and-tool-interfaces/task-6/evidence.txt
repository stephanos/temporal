  MinimizeSpec.Executor, ReplaySpec.Executor. Nothing added or changed.

  production. Explore/Resume/RunCampaignShard/Replay/Minimize call exploreWith/resumeWith/

Characterization pins (9b5ae6b39, unchanged assertions after migration)
- simulationCapabilityForJob: coordinator role only for processExecutor.
- Replay: "supervisor command is required" only without an executor; verify-only needs neither;
  a substituted replay gets no coordinator simulation role and needs no supervisor.
- Minimize: same supervisor rule; the default replayer runs replays through the substituted
  executor ("replay minimization candidate: execute replay target: ..." from the fake).
- RunCampaignShard and Resume: the pinned toolchain identity (missing root -> os.ErrNotExist) and
  the resume supervisor rule apply only without an executor.
- Isolated Explore rejects an injected executor, preparer or replayer with the same message.
- Found while pinning (pre-existing, unchanged): a substituted replay with neither supervisor nor
  bootstrap command panics in replayBootstrapCommand. Previously reachable via the public field,
  now only from same-package tests.
