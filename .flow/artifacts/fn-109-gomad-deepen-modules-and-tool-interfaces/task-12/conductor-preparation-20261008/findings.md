## Ownership and error precedence to preserve

Opening owns a pinned `os.Root`; the caller closes that handle. `Close` clears its root even if root Close fails. Detached publication values and snapshots need no Close. Their metadata remains useful after handle closure; metadata access on a nil handle is not a promised contract. `Snapshot.TargetSharing` is empty; publication alone sets sharing. `OpenPayload` transfers a separately opened payload file to its caller, which must close it.

`OpenPayload` and `CopyPayload` check nil/closed before listing. `ReadPayload` checks a nil receiver first, but on a closed nonnil handle preserves listing and bound checks before calling OpenPayload. Thus a closed handle plus an unlisted path returns the unlisted error, and a closed handle plus an undersized bound returns the bound error. The existing closed-handle test checks only a valid listed path with a sufficient bound. If one small new R18 characterization is needed, add those two combined-invalid ReadPayload cases, paired with OpenPayload's closed-first result. Do not homogenize the operation ordering.

`CopyPayload` validates its source before exclusively creating the destination. Its task 30 defers close destination before source and never close the Opened root. A nil cleanup preserves the concrete primary error; a sole cleanup error is returned directly; concurrent operation/destination/source failures retain that traversal order through joins. Task 29 private payload cleanup, task 31 directory/shared verification and task 35 corpus cleanup retain separate evidence. Their real-file and mutation checks do not establish genuine first-Close OS-fault coverage. No new fault-injection framework, descriptor theft or duplicate cleanup test is required by task 12.

`runner.preflight` now captures the opened handle in a local so its failure defer closes the actual root before returning nil. It joins validation error first and Close second. This was the declared migration repair. `replayWith` only promotes handle-close failure when no earlier replay error exists. `minimizationSession.acceptedInput` receives a copied manifest; retained result publication uses Snapshot before Close. `qualification/set.execution.go` validates artifact identity, then projects choices, then updates counts and joins artifact error before handle Close. Campaign retained-evidence resolution copies metadata, closes, then checks campaign identity. Preserve these distinct caller policies.
