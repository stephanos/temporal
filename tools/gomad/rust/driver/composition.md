# Frozen qualification composition

`compose.py --inputs INPUTS --base BASE --plan STATIC_PLAN --output BINDINGS --config FUTURE_CONFIG`
keeps the original 96 labels, installs the reviewed static recipes for the first
24, preserves the independently typed runtime/workload/SQLite bindings, assigns
the live families and fixes the eight final obligations to their actual readers.
It does not execute qualification. `sent_epoch` must already name the original
send time; the 3600 second bound includes composition and freezing.

Inputs have exactly `schema: gomad.driver-composition-inputs/v1`, `python` (the
canonical interpreter path), and `static` (the existing
`gomad.driver-static-inputs/v1` object). `static.driver_config` and
`FUTURE_CONFIG` must be equal. The base supplies the actual binary, build receipts,
installations, runtime harness, scenarios, independent SQLite oracle, live corpus,
private observations, `final_profiles`, `final_retained`, `stress`, and
`public_verbs: {bindings: ABSOLUTE_ALL_VERB_BINDINGS}`. Generated bindings are
published only after preflight succeeds. The existing `configure.py` then freezes
the resulting bindings. No future producer output digest belongs in these inputs.

The final sections run stress first and public verbs last. The public reader
executes the fixed `scripts/all-verb-parity` once, authenticates its fresh process
journals, aggregate, complete raw inventory, fixed lane commands and all original
source/custody and golden files. Retained and operator final readers use `--read-only`; their stage-owned
producers must already have retained their raw proof. Ringpop inspection produces
and independently reads its fresh evidence during final collection.

Composition refuses pending original stage producers and arbitrary caller command
bindings. Fourteen fixed primary routes cover the actual native measurement/helper builds, ordinary/conformance publication, conformance helper build,
original terminal wire controls, durable restart, ten grouped busy repetitions,
busy boundary/crash cells, independent streams, committed storage recovery,
named reset/retry, all three inspection owners, retained artifacts and detached
operators. `primary` supplies exactly `compiler`, `runtime_root`, `cache` and
`captured_config`; all executable/template roles come from the sealed live corpus.
Broad provider, functional, retained-cluster, ordinary and the remaining build,
publication and terminal recipes stay refused until their original predicates
have actual closed native readers. The current source frontier therefore remains
explicit; this is not an executable complete qualification plan yet.

`runtime` supplies only `harness` and `harness_build_receipt`. The compiler emits
exactly the 32 original `runtime-N` entries plus the separate original
`runtime-aggregate` stage. All ten mandatory cells use generated original requests,
including the existing owner's durable SQLite and independent replication
scenarios. Actual `multi-instance-cooperative` installation admission is required.
Replication source custody is copied into its private stage root when executing;
final receiving only verifies the sealed derivation. No future module digest is
placed in a frozen request. Four durable cell readers independently reopen raw
oracles, histories, process journals, measured results and actual private
preparation captures. `sqlite_oracle` is the reviewed independent actual native
state/context oracle command; missing executable inputs refuse freezing.

Freezing creates `stress-cycle.json` from the exact static input table, then a
new `public-verbs-bindings.json` whose `stress-cycle` file entry pins that plan.
The final configuration seals both documents. The plan excludes these generated
documents and never contains a future output digest. Caller supplied cycle plans
are refused; `stress_cycle` may be omitted or set to `GENERATE`. Public verbs
requires this cycle's exact static footprint and independently calls the stress
raw reader after authenticating the lane commands.

`native_measurement: {admission: ABSOLUTE_NATIVE_RELEASE_ADMISSION}` supplies the
sealed ordinary bootstrap. Freezing expands its actual build receipt, compiler and
source inputs, Cargo artifact, admitted executable and raw staging journals.
`native_roles.validate_build(config, path, role)` and `validate_admission` reopen
that complete chain and rederive source and compiled implementation identities.
Both original build stages execute the fixed native build producer in separate
fresh process roots. Publication executes native helper staging, copies the
separate conformance executable and authenticates installed ordinary discovery.
Role dictionaries use the native tagged schema: `{"kind":"release"}`, `warm`,
`stress`, or `{"kind":"diagnostic","features":[...]}` with the three reviewed
diagnostic feature combinations. Future build paths come from that same cycle's
actual producer stdout; they are never inserted into prefreeze input hashes.
