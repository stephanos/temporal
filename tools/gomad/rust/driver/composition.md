# Frozen qualification composition

`compose.py --inputs INPUTS --base BASE --plan STATIC_PLAN --output BINDINGS --config FUTURE_CONFIG`
keeps the original 96 labels, installs the reviewed static recipes for the first
24, preserves the independently typed runtime/workload/SQLite bindings, assigns
the live families and fixes the eight final obligations to their actual readers.
It does not execute qualification. `sent_epoch` must already name the original
send time; the 3600 second bound includes composition and freezing.

Inputs have exactly `schema: gomad.driver-composition-inputs/v1`, `python` (the
canonical interpreter path), and `static` (the existing
`gomad.driver-static-inputs/v1` object). `static.driver_config` and
`FUTURE_CONFIG` must be equal. The base supplies the actual binary, build receipts,
installations, runtime harness, scenarios, independent SQLite oracle, live corpus,
private observations, `final_profiles`, `final_retained`, `stress`, and
`public_verbs: {bindings: ABSOLUTE_ALL_VERB_BINDINGS}`. Generated bindings are
published only after preflight succeeds. The existing `configure.py` then freezes
the resulting bindings. No future producer output digest belongs in these inputs.

The final sections run stress first and public verbs last. The public reader
executes the fixed `scripts/all-verb-parity` once, authenticates its fresh process
journals, aggregate, complete raw inventory, fixed lane commands and all original
source/custody and golden files. Retained readers use `--read-only`; their
stage-owned producers must already have retained their raw proof.

Composition currently refuses pending original stage producers. Nonstatic checked
commands require the canonical `stage_receiving.py run|read --config CONFIG
--stage LABEL` endpoint; this module must implement actual original semantic
assertions before these labels can be bound. A Python path in the repository or
a caller-provided successful receipt cannot substitute for that implementation.
The compiler does not infer original-stage PASS rows from final-section overlap.
The current source frontier is therefore explicit, not an executable complete
qualification plan.
