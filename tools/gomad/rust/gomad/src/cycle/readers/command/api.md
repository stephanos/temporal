# Receiving foundation

`RetainedSession::new(&Configured)` retains the authenticated configuration and pins the private attempt root. `read`/`write` independently open bounded private single-link bytes under that root; each read rechecks its identity. No producer-owned descriptor or cached parsed producer object is accepted as independent evidence.

`command(root,name,&process::Command,preparation_required)` uses the caller’s frozen expected command, including its actual cwd, argv, accepted exits, timeout and private context, and authenticates fresh command/process records and raw streams. It binds the frozen executable bytes, argv/cwd, epoch, PID/registration/completion, accepted result, timeout and nearest actual producer owner before capturing preparations. Public report/inspect outputs are compared with independently reopened Result/artifact data.

`artifact(path)` returns the admitted current Rust store manifest plus the bounded authenticated module, provenance and replay buffers used for decoding at this boundary. Other payloads are authenticated and released one at a time. Choice/transcript and installed output global ceilings are 1 GiB (the current installed configuration contract), other engine streams 256 MiB, modules 512 MiB and decoding metadata 16 MiB; checked aggregate arithmetic does not introduce a narrower total. These global descriptor bounds do not authenticate per-request limits. Owning measurement consumers must use the independently authenticated request and existing `measurement::evidence::ReadLimits::for_request` at their read boundary, preserving its 256 MiB output ceiling and derived aggregate. Result/preparation admission independently binds its actual request; generic artifact admission alone makes no such claim and never derives authority from a resealed record’s limits. Historical Go stores are unsupported. `result(path,reported)` reuses QualificationResult and PublicationReceipt readers for those actual schemas, then requires the frozen source/roles and final deterministic two-run/replay contract, independent artifacts and complete campaign journal ownership.

`capture_preparations(row)` authenticates the actual producer's source/binary/campaign seal, exact receipt/raw file inventory and prepared inputs through the existing campaign preparation receiver. `prepared_observation(campaign,provenance)` exposes only an observed binding. `verify_pending_preparations()` compares each Result's complete producer/campaign set and invokes B01's independently reopening installation/compiler/source inventory validation. It clears pending entries only after every check succeeds.

`authenticate_build(&mut self,...)` delegates role records to B01's shared immutable published role reader in real or dry-run configurations, then retains that exact binary authority. Later commands recheck the authenticated role's complete source/build inputs and immutable binary bytes; mutable Cargo targets and arbitrary path/hash registration are unsupported. `core_identity` recomputes the eighteen observed identity cases through the existing authoritative build-identity function with independently read frozen inputs. The cycle CLI/final endpoint router is B15-owned; no missing route is treated as success here.

`with_artifact(path, |opened| ...)` supplies the admitted current store descriptor to owning readers; after successful parsing it authenticates every payload by streaming and rechecks the named artifact and attempt root. The `artifact` convenience method bounds all entries before retaining only module/provenance/replay; unneeded streams do not become a second large in-memory map.

`authenticate_prepared_artifact(campaign,provenance)` uses an already captured actual owner and complete campaign set, then the same installation/compiler/source verifier used by pending Results. No caller owner is accepted. The current native sidecar producer/decoder and receiving contract cap the total file table at32; the historical Python capture helper's34 discrepancy does not widen that contract.

The generic Result reader recomputes qualified/target_success from actual canonical outcomes. A fully measured deterministic panic canary remains a valid retained Result; owning cell readers separately authenticate whether success or canary was expected. Private input authority starts empty. The B08-specific child admission alone may populate independently verified aliases; frozen configuration pins take precedence, and only declared detached aliases skip a live compiler reread. That admission is outside this foundation's proof.
