# Hand-written model inventory

This ledger freezes, before fn-86 moves anything, every non-test module under `Temporal.Feature`,
`Temporal.Testpilot` and `Umpire.Examples` that builds Umpire records or Testpilot Cases without
the commands, with every reader of it and a destination. `make lint-model` reads it: a production
module under those roots that imports an authoring owner directly (`Umpire.Model`,
`Umpire.Property`, `Umpire.Scenario`, `Umpire.Query`, `Umpire.Operation`, `Umpire.Case`) and is
not a row here is reported as `hand-written module not inventoried`, so the second authoring path
cannot grow unlisted. A removal decision needs repository-wide consumer evidence, never the absence
of a Lean import alone; the readers column is that evidence.

Task-start commit: `0ed26f79a81dcc5372cc70adf29434fb0677f2d2` (fn-85 closed).

Destinations: **migrate** to a named fn-86 task; **delete** with the spec that records the covered
behavior; **keep** with the reason; **drop** with the reason. A file is deleted only once every
reader in its row has a destination of its own.
